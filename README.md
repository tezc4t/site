# Portfolio — Kyllian AUGUSTE

Site portfolio statique, moderne et responsive. Contient une page d'accueil, une page "Projets" et une page "Contact".

## Contenu du dépôt
- `index.html` — page d'accueil (hero + terminal animé)
- `projets.html` — liste et cartes des projets
- `contact.html` — cartes de contact + formulaire
- `styles.css` — styles globaux (thème sombre, fond mesh gradient flou, animations, responsive)
- `script.js` — scroll header, nav active, reveal des cartes, effet machine à écrire du terminal

## Structure et personnalisation
- Modifier `index.html`, `projets.html` et `contact.html` pour mettre à jour le contenu.
- Les styles sont centralisés dans `styles.css`. Les variables CSS en début de fichier permettent d'ajuster rapidement les couleurs et accents.
- Le fond animé est généré en CSS pur (`.bg-mesh`, 3 taches de dégradé floutées en mouvement) : aucune image à remplacer.
- Le texte tapé dans le terminal du hero se modifie dans `script.js`, tableau `codeLines`.
